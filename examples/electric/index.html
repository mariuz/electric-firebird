Two servers, one Firebird in your browser

Each list is a table in a Firebird database running in this page, kept in step with a server by firebird-wasm/electric. Adding, ticking or deleting a note asks the server; the change comes back down the shape into the local table, and db.live() redraws the list. Reload, and the sync resumes from where the local copy was.
